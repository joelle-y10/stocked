# STOCKED

Grocery intelligence: compare Canadian store prices, plan meals, track inventory, and learn to cook.

## Live site

**https://joelle-y10.github.io/stockedjoelle/**

Mirror (when available): https://joelle-pixel.github.io/stocked/

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints in the terminal (port may vary).

## Features

- **Compare** — CAD prices at Costco, Superstore, Walmart, No Frills, FreshCo, Food Basics with per-item store leaderboards
- **Favorite shops** — star one or more stores (localStorage); columns and leaderboards highlight them
- **Favorite items** — star staples you track often
- **Recipes** — detailed amounts, prep/cook times, tips & substitutions, fridge checkboxes, then a shopping trip plan for what’s missing
- **Meal plan** — search recipes for each weekday (Mon–Sun)
- **Inventory** — pantry quantities with +1 / −1 (saved in the browser)
- **Shop smart** — missing ingredients, cheapest store, best weekday, trip plan by store
- **Learn** — grocery literacy (unit prices, Canadian stores, planning, waste) plus cooking tutorials with materials, tools, and steps

Price sources are documented in `src/data/PRICE_SOURCES.md`. Figures are **approximate · as of July 2026** — not live store feeds.
